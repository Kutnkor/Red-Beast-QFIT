# Evrim tablolarını yeniden üretme

`evolution-sources/` içindeki beş kaynak tablo, `frontend/src/three/data/evolution.json` içindeki kaynak URL’leri ve SHA-256 değerleriyle eşleşir. Bunları proje kökünde `evidence/evolution-sources/` dizinine kopyalayıp `python tools/prepare_evolution.py` çalıştırın. Tam model grid arşivlerine çalışma anında gerek yoktur. Kaynak açıklamaları: `docs/EVOLUTION_EXPLORER.md`.
