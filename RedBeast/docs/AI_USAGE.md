# AI use in BlinkSpace

This disclosure separates the imported source project's history from the current work.

The imported SPHERE-X source included a disclosure attributing coding assistance to Claude
(Anthropic). That is the imported project's own statement, not independently verified
provenance for every file. Its scientific rules and source citations were retained.

The current integration was developed with **OpenAI Codex**, from the user's application
plan and supplied sources. Codex assisted with implementation, scientific data preparation,
validation, interface text, tests and documentation. The assistant does not claim authorship
by another model or add an invented co-author identity to commits.

Scientific input values and image observations come from the cited public archives and
catalogues. The code computes derived values from those inputs. Synthetic images exist in
labelled automated tests; they are not substituted for archive observations. The stellar
surface is a code-generated representative graphic, labelled as such, not a resolved image.

The distributed runtime assistant is disabled by default. This integration adds the supplied QFIT
Python agent and robin widget with its existing OpenAI gpt-5.4-mini configuration. Model responses
are labelled AI explanations; local source cards and mock responses are labelled non-AI. The
model can retrieve local source material and propose validated UI commands; it cannot execute
shell code, browse independently or silently start archive searches/save downloads. The browser
requires a user click. The private local installation can be activated with a server-only key;
no key is shipped. Live evaluation, when run, is recorded separately from offline fixture tests.
The user-supplied robin artwork is preserved, not newly generated in this integration.

Current validation results belong to the newly generated evidence reports. Imported test
counts, browser screenshots and scientific report values are not automatically evidence
for this integration. Developer browser checks are not tests with independent people.
No independent user-testing or competition-submission result is invented.
